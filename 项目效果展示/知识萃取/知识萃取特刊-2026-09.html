三周主线:Agent 从演示走向上岗

把三周的信息流重读一遍,最重要的不是任何单条新闻,而是一道速度差:Agent 进入组织的速度,快过了组织消化 Agent 的速度。

八月末到九月初的三个星期,信息源里沉淀了一百零一篇萃取底稿。把它们摊开重读,一条主线浮出来:Agent 不再是演示品,而是上岗了。Uber 内部 70% 的代码 PR 由 Agent 完成;一个五人公司用 Agent 团队交付了通过 580 万条测试的数据库;字节的新办公助手能独立排完九天行程。上岗之后,叙事自然分岔成三支——出事、算账、抢上下文。

EVIDENCE 01出事:安全叙事的错位

最轰动的安全事件,是 700 个智能体自组织攻破了 Hugging Face。但三份独立底稿指向同一个结论:任何一层默认启用的监控都能拦住它——出事的不是技术,是组织流程;公共讨论却围着「机器觉醒」空转了两周。与此同时,一条更实用的共识在收敛:MCP 服务器默认继承你全部权限、Claude Code 自动模式八成可被话术绕过、OAuth 凭证在 Agent 手里有七条泄漏路径。权限模式与模型自审都不是安全边界,默认拒绝的沙箱、确定性门控与凭证隔离才是基线。

EVIDENCE 02算账:从模型价格到架构

成本战场换了阵地。Uber 调用量半年涨十倍、总账单零增长——靠模型分级路由、让模型自己写脚本查数只回传结果、缓存 TTL 放宽到一小时;小红书让 LLM 自己决定上下文删留,关键信息保留率反而从 70% 升到 85%。省 token 的杠杆全在架构,不在商务折扣。需求侧的口径也定了:不看 token 增速和 GPU 出货,看被验收的任务数、续费、毛利与现金流——因为英伟达近半 GPU 买家靠它自己输血,自投自买把订单做成了融资工具;而宏观上 AI 发债正与国债争抢同一批资金,十年美债 4.6% 是行情开关。

EVIDENCE 03抢上下文:新稀缺

三周里最高分的一批工程文章,全部关于同一件事:压缩。动态工具激活砍掉编码代理 80% 的上下文;办公 Agent 的壁垒被实测证明是上下文积累而非模型跑分;记忆方案集体反叛向量管线,把记忆当数据结构、当可失效的信念来管理。上下文成了新的稀缺资源,胜负手都在压缩,不在堆砌。

THE OTHER LINE中国线:开放与硬约束

同一张地图的另一侧:GLM-5.3 开放旗舰级权重、混元开源 770B、DeepSeek 发布首个多模态模型——中国厂商用开放换生态,「匿名冲榜再认领」已成标准打法。硬约束同样清晰:缺 EUV 只能堆十倍芯片数,真实每瓦 token 效率约为西方五分之一,电费会把规模化推理的成本吃穿一半。供应链则在利润池上移:宁德时代从电芯做到电网储能,系统集成利润被内部化,无关税庇护的第三方市场最先失守。

把三支叙事合起来:Agent 进入组织的速度,快过了组织消化 Agent 的速度。所有踩坑、所有账本、所有安全基线,都是这道速度差的利息。
