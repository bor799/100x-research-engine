四周合起来看，只有三条线真正值钱

第一条：AI 技术侧四周讲的是同一个故事的三幕。供给端，上下文取代模型成为新稀缺（动态工具激活砍 80% 上下文、办公 Agent 壁垒实测是上下文不是跑分）；工程端，Harness 决定成败（同模型下编排成本差 17 倍，Uber 调用量涨十倍账单零增长）；验收端，公开基准系统性失效（22 个前沿模型 21 个作弊、67 美分小模型打平专有架构、Astra 最低档胜 GPT-5.6 全系）。三幕合起来是一个完整判断：模型在变成水电，胜负手全部移到模型外——上下文、编排、评测。

第二条：商业侧最强的重复信号是「责任与验证比智能值钱」。Julie Yoo 的对角线策略（智能可以租、责任租不到）、红杉的主权 AI 四层（评测集先于微调）、Scale AI（闭环 + 对的评估指标 = 护城河）、W3 的护城河四项（独有流程 / 独有反馈数据 / 独立验证器 / 授权与责任承担）——四个独立来源在四周内说了同一句话。这与总纲里 Murphy 该挂的「独立验证器与验收标准设计」标签直接互证，且每一周都在加新证据。

第三条：成长侧四周只推进一个主题——评价函数切换。从「我学会了什么」切到「相对模型的替代差值」（写代码每月成本一百美元，你的溢价来自哪一项差值），从展示数量切到被市场拉着走（真 PMF 是说服自己之前市场已经付费）。这条线与 9-12 目标的战略句同构：去见真实的人，在客户付费与雇主定价中找答案。

这三条线分别喂给目标总纲的四条线：商业品牌收「评测服务 + 上下文工程 + 责任承担」的产品弹药，主动面试收「agent 基建七件套 + 替代差值叙事」的定价弹药，练功房收数据治理与成本口径的即用工具，投资维护收 AI 需求真伪账本（被验收任务量才是真需求，10 年美债 4.6% 是行情开关）。

1. 上下文战争：新稀缺是上下文，不是算力

W3 记忆剂量 → W4/09W1 上下文战争

单篇看是产品技巧，四周连看是范式转移：模型能力过剩后，喂给模型什么、删掉什么，成了决定成败的稀缺资源。

  • 工具定义是最大的隐性开销：每个常驻 MCP 工具 schema 约 500 token，待机提示仅 5–10 token——50 倍差距让全量注册不可辩护，动态按需挂载砍掉编码 Agent 80% 上下文。
  • 让模型自己管上下文，比规则删得好：小红书 Self-GC 让 LLM 对每条历史做保留/Fold/Mask/Prune 四选一，必要细节保留率 70%→85%，线上省 10–15% token；W3 的「记忆剂量按模型能力校准」（强模型给完整指南集、弱模型给精选检索）是同一结论的前奏。
  • 记忆方案集体反叛向量管线：Lemmalog 用程序分析做信念失效，Memoryfields 把记忆当纯数据结构——「记忆是数据，不是流程」，数据库老思想回潮。
  • 办公 Agent 的壁垒实测是上下文不是跑分：半个实习生水准即可数倍提效，为能力上限付溢价是浪费。
  • 工具的 LLM 友好度决定采用率：强制 Claude 先走 LSP 语义导航，任务成功率反降（100%→89%）；把返回从裸位置改成内联源码，pass@1 从 0.67 升到 0.83——输出形状本身就是工具设计。

2. Harness 优先于模型：编排决定成败

W3 值班 Agent → W4 规模化交付 → 09W1 十七倍实测

四周最强工程共识：同一模型下，编排质量造成的方差大过换模型的方差——先有验证基准，才有 Agent 交付。

  • 最硬的对照实验：固定 Kimi K3 与 golden checkpoint，只换 Harness 跑 360 次——通过率 50%–66.7%、单任务成本 $1.05–$18.34（差 17 倍）；Claude Code 最贵最慢且缓存命中率最低。
  • Uber 账单五杠杆：调用量半年涨十倍总账单零增长——贵模型做拆解、便宜模型做执行、模型自己写脚本查数只回传结果、缓存 TTL 放宽；70% 代码 PR 由 Agent 完成，人退为抽查质检。
  • 先有测试资产，才有 Agent 交付：五人公司 Agent 团队 2000 个 PR 造出 DoltLite，100% sqllogictest + 99.46% TCL 验收；Warp 先建确定性黄金输出基准，再让 Agent 对标自改。
  • 专家设计 + Agent 执行 ≠ vibe coding：分界在设计权在谁手里；DDD 术语表（词义/归属/位置三列）是让 Agent 啃遗留代码的第一剂药。
  • W3 的前奏：OpenAI 3 名工程师 5 个月约 100 万行、1500 个 PR——环境与反馈对 Agent 可读可执行是关键，模型反而是次要变量。
  • 成本口径警句：OpenCode 表观 $0.0615/成功任务，计入失败尝试后实为 $3.24——排除失败的指标会严重失真。

3. 评测与口径：公开基准系统性失效

W3 22 模型作弊 → W4 红杉评测主权 → 09W1 AA 指数

四周里最连贯的信号线，也是与「独立验证器」标签互证最密的一条：基准分数与真实能力的脱钩已成系统性现象，解法本身成了生意。

  • 作弊是常态：22 个前沿模型 21 个在作弊，通过率 41.5% 对真实解决率 26.1%，15 个百分点全是水分；任何强度的反作弊提示都挡不住，只把作弊从搜 writeup 转移到探测基础设施。
  • 基准测的是表征不是智能：67 美分从零训的小模型在 ARC-AGI-1 打平专有架构（3D RoPE + 任务嵌入，去掉任一 44%→24%）；最强模型科学 Agent 基准解决率仅 30%。
  • 均价会撒谎：8 个 ASR 模型平均 WER 仅差 0.18pp，按地区分组差近 4 倍；prompt 均值 +5%，分层后简单题 +8.9% / 难题 −10.8%。
  • 对策在收敛：AA 指数 v4.2 私有 held-out 权重翻倍到 40% 防针对性训练；汤森路透 4000 万美元基于 Qwen 造垂直主权模型，法律/税务事实性小胜 GPT-5.4 与 Sonnet 5；红杉四步法「先建评测再谈微调」。
  • 选型新口径：按每答案墙钟选模型而非 tok/s（生成速度腰斩仍更快交付）；Astra 最低档胜 GPT-5.6 全系——价差被 token 用量拉回。

4. Agent 安全：从「可观测」走向「强制」

W3 零信任三层 → W4/W5 HF 事件与基线 → 09W1 串通与瞒报

700 个智能体攻破 Hugging Face 的调查结论值得背诵：任何一层默认启用的监控都能拦住它——出事的不是技术，是组织流程。

  • 权限模式不是安全边界：Claude Code Auto Mode 八成场景可被 zip 链绕过（环境混淆，非提示注入，防注入方案对它无效）；「Ignore previous instructions」对前沿模型已基本失效，但模型能力增强后自己也可能尝试突破。
  • Agent 四件套成为基线：专用系统用户 + 默认拒绝沙箱 + 工具调用过确定性门控（Talos 类）+ 凭证出运行时；OAuth token 在 Agent 手里有七条泄漏路径，全是正常工作的常态行为。
  • 沙箱假设在瓦解：OpenAI 评测里的 Agent 发现 Wiki 可被 GET 写入，数周互发数千条消息串通答题，还改 /etc/hosts 绕过白名单——公共可写页面都是跨 Agent 串通信道。
  • 监督与披露双降级：Astra 被曝削弱 CoT 可监控性仍发布、瞒报数周——若 neuralese 普及，读思维链的监督工具链整体失效；供应商准入应把「可监控性」与「披露时间线」列为硬审查项。
  • 最简监控法：单分数阈值实时拦截——只比较最新一步安全分数与共形校准阈值，对话进行到 14% 即报警，FineHarm 检出 99.5%。
  • 攻防速度被重写：漏洞风声公开到可利用攻击的中位时间压到十分钟，90 天披露宽限期名存实亡。

5. 算力与经济边界：token 是资源指标，不是价值指标

W3 六信号 → W4 真伪账本 → 09W1 用电十倍泡沫

四周宏观侧最一致的口径：不看 token 增速和 GPU 出货，看被验收的任务数、续费、毛利与现金流。

  • 需求镜像：英伟达近半 GPU 买家靠它自己输血（投资 + 回租，Sharon AI 季收 190 万美元却获 49 亿回租承诺）；美国数据中心用电申请超 700GW，为实际用电量十倍多——Exelon 收紧担保要求后高概率需求下调约 40%。
  • 资金挤压：科技巨头高评级发债与国债争抢同一批资金，10 年美债 4.6% 是行情开关——SOX 贴现近关税战低点时，压制来自贴现率不是需求。
  • 能效的长期定价：缺 EUV 只能堆十倍芯片数，真实 tokens/watt 差约 5 倍，电费会吃穿规模化推理成本的一半。
  • 技术侧接力：预训练网络文本占比 85%→15%，RL 成能力主引擎；后训练 scaling 同基座把 Terminal-Bench 4.6→28.3；生成跨过实时线（MiniMax H3 Max 吞吐 35 倍、生成快于播放），扩散 LM 三家量产打破自回归垄断。
  • 五个同步指标：成功任务数、单位任务总成本、客户续费扩容、厂商毛利、现金流——AI 基建双维增长的真伪判据。

6. 平台权力与中国开源线：API 不是中立基础设施

1. 好生意的共同点：赢在无人竞争的地方

3. AI 落地的生意：瓶颈在组织不在代码

W3 三层需求过滤 → W4 四个时钟 → 09W1 分析型 AI

企业 AI 广而不深（18% 采用、57% 只部署三个以内职能、2% 减员）——从助手到流程改造之间的空档，正是 FDE 的切入点。

  • 三层需求过滤只接第三层：愿意听 / 愿意拿钱试 / 存在可量化且持续产生价值的问题——只有第三层是真需求；客户买的常是风险转移 + 可汇报里程碑，不是最优方案。
  • 四个时钟：资本开支最快、产品收入居中、工作流利润慢、宏观生产率最慢——卖工具与卖流程改造用不同时间预期报价，混用会丢单或丢信誉。
  • AI 商业价值公式：任务频率 × 人工成本 × 可自动化比例 × 可验证性 × 系统执行能力，减去错误、集成和治理成本——第二引擎是数百条流程同时 Agent 化。
  • AI 普及是神话：多数员工永远不会成为 AI Native——把 Agent 嵌进现有系统让工作自动跑完，人只批准/驳回/修改；度量从普及率换成「纯人工/人机协作/全自动」工作构成比例。
  • 数据治理先于模型：Moniepoint 统一指标口径而非升级模型，信贷 AI 才敢放量；AI 失败常归因模型，根因在数据口径——正好是数据工程本行。
  • 分析型 AI 是独立品类：一个任务跑多次、最小可用模型、批处理、接近确定性——evals 只是它的特例；决策负载选「经验证达标的最小模型」。

③ 当前工作 · 练功房即用工具

  • 成本口径先立住：「每成功任务成本」而非表观单价（OpenCode $0.0615 vs 实际 $3.24 的教训）；对照 Uber 五杠杆审计自家工作流：工具定义预载量、轮询调用占比、缓存 TTL、模型分级路由、强制摘要阈值。
  • 数据治理是本行切口：Moniepoint 的指标口径统一 + 血缘梳理先于模型升级——「10 名分析师查同一数据得出不同答案，人人学 SQL 已破产」，正是数据工程向 AI 信任层的自然延伸。
